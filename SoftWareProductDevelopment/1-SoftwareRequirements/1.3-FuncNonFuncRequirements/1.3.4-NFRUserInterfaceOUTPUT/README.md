### Опис вимог до OUTPUT-потоків інтерфейсу користувача

| ID | Нефункціональна вимога | Опис |
|----|------------------------|------|
| **NFR-OUT1** | Відображення середнього рейтингу якості | Система повинна відображати середній рейтинг якості творчих сесій за обраний період як числове значення з точністю до 0.1 у форматі «X.X / 10» |
| **NFR-OUT2** | Відображення списку творчих сесій | Система повинна відображати список творчих сесій у вигляді таблиці зі стовпцями: «Дата», «Тип», «Тривалість (хв)», «Назва», «Якість (1–10)» |
| **NFR-OUT3** | Відображення аналітики кореляцій | Система повинна відображати виявлені кореляції у вигляді текстових карток з виділенням сильних кореляцій (|r| > 0.6) зеленим кольором, слабких — сірим |
| **NFR-OUT4** | Відображення тенденцій | Система повинна відображати динаміку рейтингу якості творчих сесій у вигляді лінійного графіку, де вісь X — дата, вісь Y — середній рейтинг |
| **NFR-OUT5** | Повідомлення про успішне збереження | Система повинна відображати підтверджувальне повідомлення «Запис збережено» протягом 2 секунд після додавання творчої сесії або запису стану дня |
