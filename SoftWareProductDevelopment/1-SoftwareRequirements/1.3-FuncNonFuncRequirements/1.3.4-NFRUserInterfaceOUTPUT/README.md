### Опис вимог до OUTPUT-потоків інтерфейсу користувача

| ID | Нефункціональна вимога | Опис |
|----|------------------------|------|
| **NFR-OUT1** | Відображення калорійності раціону | Система повинна відображати загальну калорійність денного раціону як числове значення з точністю до 1 ккал у форматі «XXXX ккал» |
| **NFR-OUT2** | Відображення списку продуктів | Система повинна відображати список продуктів денного раціону у вигляді таблиці зі стовпцями: «Продукт», «Кількість (г)», «Калорії (ккал)», «Білки (г)», «Жири (г)», «Вуглеводи (г)» |
| **NFR-OUT3** | Відображення рекомендацій | Система повинна відображати рекомендації щодо харчування у вигляді текстових карток з виділенням нутрієнтів, яких не вистачає, червоним кольором |
| **NFR-OUT4** | Відображення фізичних показників | Система повинна відображати динаміку ваги у вигляді лінійного графіку, де вісь X — дата, вісь Y — вага у кг |
| **NFR-OUT5** | Повідомлення про успішне збереження | Система повинна відображати підтверджувальне повідомлення «Запис збережено» протягом 2 секунд після додавання продукту до раціону |
