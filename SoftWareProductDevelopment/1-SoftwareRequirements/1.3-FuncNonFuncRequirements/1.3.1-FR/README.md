### Опис функціональних вимог

Функціональні вимоги сформовано на основі BDD-специфікацій Feature1 (UC2: Записати раціон) та Feature3 (UC3: Рекомендації).

---

## FR1 — Система записування раціону харчування

| ID | Вимога |
|----|--------|
| **FR1** | Система повинна надавати можливість музиканту вести щоденний облік раціону харчування |
| **FR1.1** | Система повинна надавати можливість музиканту додавати продукт харчування із зазначенням його назви та кількості (у грамах) до денного раціону |
| **FR1.2** | Система повинна автоматично розраховувати загальну кількість калорій денного раціону музиканта на основі введених продуктів |
| **FR1.3** | Система повинна надавати можливість музиканту переглядати перелік продуктів поточного денного раціону |
| **FR1.4** | Система повинна надавати можливість музиканту видаляти продукт харчування з поточного денного раціону |

## FR2 — Система надання рекомендацій щодо харчування

| ID | Вимога |
|----|--------|
| **FR2** | Система повинна надавати музиканту персоналізовані рекомендації щодо харчування |
| **FR2.1** | Система повинна порівнювати поточний добовий раціон музиканта зі стандартними нормами споживання калорій та нутрієнтів |
| **FR2.2** | Система повинна надавати музиканту текстові рекомендації щодо коригування раціону у разі відхилення від норм споживання нутрієнтів |
| **FR2.3** | Система повинна відображати музиканту список продуктів, яких не вистачає у поточному раціоні для досягнення добової норми нутрієнтів |
