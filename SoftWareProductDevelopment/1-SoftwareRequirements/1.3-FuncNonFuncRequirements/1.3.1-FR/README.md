### Опис функціональних вимог

Функціональні вимоги сформовано на основі BDD-специфікацій Feature1 (UC1: Записати творчу сесію) та Feature3 (UC3: Переглянути аналітику).

---

## FR1 — Система управління творчими сесіями

| ID | Вимога |
|----|--------|
| **FR1** | Система повинна надавати можливість творчій людині вести облік творчих сесій |
| **FR1.1** | Система повинна надавати можливість творчій людині додавати творчу сесію із зазначенням дати, тривалості (хвилин), типу творчості, назви та рейтингу якості (від 1 до 10) |
| **FR1.2** | Система повинна автоматично обчислювати середній рейтинг якості творчих сесій за обраний період |
| **FR1.3** | Система повинна надавати можливість творчій людині переглядати список своїх творчих сесій |
| **FR1.4** | Система повинна надавати можливість творчій людині видаляти творчу сесію зі свого журналу |

## FR2 — Система ведення щоденного журналу стану

| ID | Вимога |
|----|--------|
| **FR2** | Система повинна надавати можливість творчій людині вести щоденний журнал свого стану |
| **FR2.1** | Система повинна надавати можливість творчій людині записувати щоденний стан із зазначенням кількості годин сну, рівня енергії (1–10), настрою (1–10) та рівня стресу (1–10) |
| **FR2.2** | Система повинна надавати можливість творчій людині додавати записи харчування до щоденного журналу |
| **FR2.3** | Система повинна надавати можливість творчій людині редагувати запис щоденного стану |

## FR3 — Система аналітики та рекомендацій

| ID | Вимога |
|----|--------|
| **FR3** | Система повинна надавати творчій людині аналітику та персоналізовані рекомендації |
| **FR3.1** | Система повинна обчислювати кореляції між факторами щоденного стану (сон, харчування, настрій) та рейтингом якості творчих сесій |
| **FR3.2** | Система повинна відображати тенденції якості творчості та факторів стану за обраний творчою людиною період |
| **FR3.3** | Система повинна формувати персоналізовані рекомендації для покращення якості творчих сесій на основі виявлених кореляцій |
