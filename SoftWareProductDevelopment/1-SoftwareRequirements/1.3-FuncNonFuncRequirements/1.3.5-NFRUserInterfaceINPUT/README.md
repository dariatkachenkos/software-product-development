### Опис вимог до INPUT-потоків інтерфейсу користувача

| ID | Нефункціональна вимога | Опис |
|----|------------------------|------|
| **NFR-IN1** | Поле «Назва продукту» | Поле повинно приймати текстовий рядок довжиною від 2 до 100 символів; забороняються символи: `< > { } [ ]` |
| **NFR-IN2** | Поле «Кількість (г)» | Поле повинно приймати лише позитивні числа (цілі або десяткові з крапкою); діапазон: 1–5000 |
| **NFR-IN3** | Поле «Вага (кг)» | Поле повинно приймати лише позитивні десяткові числа з крапкою; діапазон: 20.0–300.0 |
| **NFR-IN4** | Поле «Дата» | Поле повинно використовувати формат DD.MM.YYYY; забороняється введення майбутніх дат |
| **NFR-IN5** | Пошук продукту | Поле пошуку повинно реагувати на введення від 2 символів та відображати підказки у реальному часі (не пізніше 500 мс після введення) |
