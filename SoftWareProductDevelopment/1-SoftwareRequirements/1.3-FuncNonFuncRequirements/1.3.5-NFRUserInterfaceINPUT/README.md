### Опис вимог до INPUT-потоків інтерфейсу користувача

| ID | Нефункціональна вимога | Опис |
|----|------------------------|------|
| **NFR-IN1** | Поле «Назва сесії / страви» | Поле повинно приймати текстовий рядок довжиною від 2 до 200 символів; забороняються символи: `< > { } [ ]` |
| **NFR-IN2** | Поле «Тривалість (хв)» | Поле повинно приймати лише цілі позитивні числа; діапазон: 1–1440 |
| **NFR-IN3** | Поле «Рейтинг якості / рівень енергії / настрій / стрес» | Поле повинно приймати лише цілі числа; діапазон: 1–10 |
| **NFR-IN4** | Поле «Кількість годин сну» | Поле повинно приймати позитивні числа з кроком 0.5; діапазон: 0.0–24.0 |
| **NFR-IN5** | Поле «Дата» | Поле повинно використовувати формат DD.MM.YYYY; забороняється введення майбутніх дат |
