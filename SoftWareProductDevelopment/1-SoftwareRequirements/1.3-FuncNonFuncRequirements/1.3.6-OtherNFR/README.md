### Опис основних нефункціональних вимог, не пов'язаних з інтерфейсом користувача

| ID | Категорія | Нефункціональна вимога |
|----|-----------|------------------------|
| **NFR-P1** | Продуктивність | Час відповіді API на запит збереження творчої сесії або запису стану дня не повинен перевищувати 1 секунди при навантаженні до 100 одночасних користувачів |
| **NFR-P2** | Продуктивність | Час обчислення кореляцій та генерації рекомендацій не повинен перевищувати 3 секунд |
| **NFR-S1** | Безпека | Паролі користувачів повинні зберігатися у базі даних у хешованому вигляді (bcrypt, salt ≥ 10) |
| **NFR-S2** | Безпека | Доступ до особистих даних творчої людини повинен бути обмежений лише авторизованим власником облікового запису |
| **NFR-A1** | Доступність | Система повинна бути доступна не менш ніж 99% часу на місяць (допустимий простій: ≤ 7.2 год/місяць) |
| **NFR-M1** | Зручність обслуговування | Код застосунку повинен бути покритий unit-тестами не менш ніж на 70% |
| **NFR-PO1** | Переносимість | Застосунок повинен коректно працювати у браузерах Chrome (v100+), Firefox (v100+), Edge (v100+) |
