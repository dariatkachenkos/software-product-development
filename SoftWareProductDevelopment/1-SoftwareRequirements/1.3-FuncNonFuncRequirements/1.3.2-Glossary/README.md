### Глосарій термінів

| Термін | Визначення |
|--------|------------|
| **Музикант** | Користувач системи — особа, яка займається написанням музичних творів як самоактуалізацією |
| **Раціон харчування** | Перелік продуктів харчування із зазначенням їх кількості, що були спожиті протягом одного дня |
| **Продукт харчування** | Будь-який харчовий продукт, що має нутрієнтний склад (назва, калорійність, вміст білків, жирів, вуглеводів на 100 г) |
| **Нутрієнт** | Поживна речовина, що входить до складу продукту харчування: білки, жири, вуглеводи, вітаміни, мінерали |
| **Калорійність** | Кількість енергії (у ккал), що міститься у 100 г продукту харчування |
| **Добова норма** | Рекомендована кількість калорій та нутрієнтів для споживання протягом одного дня для людини з певними фізичними характеристиками |
| **Фізичні показники** | Виміряні характеристики тіла музиканта: вага (кг), ріст (см), ІМТ |
| **ІМТ (Індекс маси тіла)** | Розрахункова величина, що характеризує співвідношення ваги та зросту людини: ІМТ = вага(кг) / (зріст(м))² |
| **Персоналізована рекомендація** | Порада щодо коригування раціону харчування, сформована на основі індивідуальних фізичних показників конкретного музиканта |
| **Денний раціон** | Сукупність всіх продуктів харчування, введених користувачем за конкретний календарний день |
