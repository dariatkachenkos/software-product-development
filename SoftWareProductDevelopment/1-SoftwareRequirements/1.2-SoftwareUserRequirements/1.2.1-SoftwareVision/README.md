### Бачення програмного продукту

| Елемент | Опис |
|---------|------|
| **FOR** | Музикантів-композиторів, які займаються написанням музики як самоактуалізацією |
| **WHO** | Потребують зручного інструменту для підтримки здорового харчування та фізичного стану без відволікання від творчого процесу |
| **THE** | «MusicHealth» — веб-застосунок підтримки здорового способу life музиканта-композитора |
| **IS A** | Система моніторингу харчування та фізичних показників з персоналізованими рекомендаціями |
| **THAT** | Дозволяє користувачу швидко вести щоденник харчування, відстежувати фізичні показники та отримувати персоналізовані рекомендації для підтримки здоров'я і творчого потенціалу |
| **UNLIKE** | MyFitnessPal, Google Fit, Cronometer та інших загальних застосунків здоров'я |
| **OUR PRODUCT** | Орієнтований на особливості творчого графіку: мінімалістичний інтерфейс для швидкого введення даних, нагадування, що враховують творчі сесії, та підтримка балансу між музичною творчістю й особистим life |

## Короткий опис

**MusicHealth** — веб-застосунок, що допомагає музиканту-композитору:
- вести щоденний облік раціону харчування з автоматичним розрахунком калорій та нутрієнтів;
- відстежувати динаміку фізичних показників (вага, ІМТ);
- отримувати персоналізовані рекомендації щодо харчування на основі своїх фізичних показників;
- отримувати нагадування про прийом їжі, щоб не пропускати їжу під час творчих сесій.

**Мова інтерфейсу:** українська  
**Платформа:** веб-браузер (ПК / смартфон)  
**Технологічний стек:** JavaScript (Node.js + Express), PostgreSQL
