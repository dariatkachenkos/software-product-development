### Бачення програмного продукту

| Елемент | Опис |
|---------|------|
| **FOR** | Творчих людей (музикантів, письменників, художників, дизайнерів), що прагнуть розуміти зв'язок між способом життя та якістю своєї творчості |
| **WHO** | Потребують зручного інструменту для відстеження щоденних факторів життя і творчих сесій без необхідності ручного аналізу |
| **THE** | «CreativeFlow» — веб-застосунок відстеження якості творчого життя |
| **IS A** | Система ведення журналу творчих сесій та щоденного стану з автоматичним виявленням кореляцій та персоналізованими рекомендаціями |
| **THAT** | Дозволяє користувачу за кілька хвилин на день фіксувати творчі сесії та стан життя, а потім отримувати аналітику: за яких умов (сон, харчування, настрій) його творчість найкраща |
| **UNLIKE** | Daylio, MyFitnessPal, Notion та інших загальних застосунків |
| **OUR PRODUCT** | Єдиний інструмент, що поєднує трекер творчих сесій з журналом щоденного стану та автоматично знаходить персональні кореляції, перетворюючи дані на практичні рекомендації |

## Короткий опис

**CreativeFlow** — веб-застосунок, що допомагає творчій людині:
- фіксувати творчі сесії з оцінкою якості (1–10), тривалістю та типом творчості;
- вести щоденний журнал стану: сон, рівень енергії, настрій, стрес, харчування;
- переглядати аналітику кореляцій між факторами життя та якістю творчих сесій;
- отримувати персоналізовані рекомендації для покращення творчої продуктивності.

**Мова інтерфейсу:** українська  
**Платформа:** веб-браузер (ПК / смартфон)  
**Технологічний стек:** JavaScript (Node.js + Express), PostgreSQL
