### Цільова аудиторія споживачів програмного продукту

**Основна цільова аудиторія — творчі люди, що слідкують за якістю свого life:**

| Характеристика | Опис |
|----------------|------|
| **Соціальний статус** | Музиканти, письменники, художники, дизайнери, композитори — люди, для яких творча діяльність є важливою частиною самоактуалізації |
| **Вік** | 18–45 років |
| **Рівень технічної грамотності** | Базовий та середній (користуються смартфоном, браузером) |
| **Спосіб роботи** | Нерегулярний творчий графік, тривалі творчі сесії, підвищене розумове та емоційне навантаження |
| **Проблема** | Творча продуктивність різко коливається, але причини невідомі — немає інструменту для виявлення особистих закономірностей |
| **Мотивація** | Зрозуміти, за яких умов творчість розквітає, і свідомо формувати ці умови |
| **Пристрій** | Смартфон (основний), ПК / ноутбук (додатковий) |

**Вторинна аудиторія:**
- Студенти творчих спеціальностей
- Будь-які люди, що прагнуть покращити якість свого life через самоспостереження
