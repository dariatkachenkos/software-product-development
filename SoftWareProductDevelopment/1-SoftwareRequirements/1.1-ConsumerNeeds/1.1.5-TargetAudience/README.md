### Цільова аудиторія споживачів програмного продукту

**Основна цільова аудиторія — музиканти-композитори:**

| Характеристика | Опис |
|----------------|------|
| **Соціальний статус** | Музиканти, композитори, студенти музичних закладів, аматори, що займаються написанням музики як самоактуалізацією |
| **Вік** | 18–45 років |
| **Рівень технічної грамотності** | Базовий та середній (користуються смартфоном, браузером) |
| **Спосіб роботи** | Нерегулярний творчий графік, тривалі сесії написання музики, пропуск прийомів їжі під час натхнення |
| **Проблема** | Через захопленість творчим процесом нехтують правильним харчуванням та фізичним здоров'ям, що призводить до фізичного виснаження та напруги у стосунках |
| **Мотивація** | Підтримка здоров'я для збереження творчого потенціалу та гармонії у стосунках кохання |
| **Пристрій** | Смартфон (основний), ПК / ноутбук (додатковий) |

**Вторинна аудиторія:**
- Студенти творчих спеціальностей (музика, мистецтво)
- Будь-які люди з нерегулярним творчим графіком (художники, письменники)
