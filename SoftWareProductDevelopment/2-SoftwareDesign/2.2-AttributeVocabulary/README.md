### Словник атрибутів об'єктів

| Об'єкт | Атрибут | Короткий опис | Тип | Обмеження |
|--------|---------|---------------|-----|-----------|
| Музикант | ім'я | Ім'я користувача | string(50) | NOT NULL, 2–50 символів |
| Музикант | прізвище | Прізвище користувача | string(50) | NOT NULL, 2–50 символів |
| Музикант | email | Електронна адреса (логін) | string(100) | NOT NULL, унікальний, формат email |
| Музикант | дата_народження | Дата народження | date | NOT NULL, не пізніше поточної дати |
| Музикант | вага | Поточна вага у кг | decimal(5,1) | > 0, ≤ 300 |
| Музикант | зріст | Зріст у см | integer | > 0, ≤ 300 |
| РаціонДня | дата | Дата раціону | date | NOT NULL, не пізніше поточної дати |
| ПродуктХарчування | назва | Назва продукту | string(100) | NOT NULL, 2–100 символів, без < > { } |
| ПродуктХарчування | калорії_на_100г | Калорійність на 100 г | decimal(6,2) | ≥ 0, ≤ 9000 |
| ПродуктХарчування | білки_на_100г | Вміст білків на 100 г | decimal(5,2) | ≥ 0, ≤ 100 |
| ПродуктХарчування | жири_на_100г | Вміст жирів на 100 г | decimal(5,2) | ≥ 0, ≤ 100 |
| ПродуктХарчування | вуглеводи_на_100г | Вміст вуглеводів на 100 г | decimal(5,2) | ≥ 0, ≤ 100 |
| ЗаписПродукту | кількість_г | Кількість продукту у грамах | decimal(6,1) | > 0, ≤ 5000 |
| ЗаписПродукту | час_додавання | Час внесення запису | timestamp | NOT NULL |
| ФізичнийПоказник | тип_показника | Тип показника (вага, ІМТ) | string(30) | NOT NULL |
| ФізичнийПоказник | значення | Числове значення показника | decimal(6,2) | NOT NULL, > 0 |
| ФізичнийПоказник | дата_виміру | Дата вимірювання | date | NOT NULL, не пізніше поточної дати |
| Рекомендація | текст | Текст рекомендації | text | NOT NULL |
| Рекомендація | дата_генерації | Дата створення рекомендації | timestamp | NOT NULL |
| Рекомендація | тип_нутрієнту | Нутрієнт, якого не вистачає | string(30) | NOT NULL |
