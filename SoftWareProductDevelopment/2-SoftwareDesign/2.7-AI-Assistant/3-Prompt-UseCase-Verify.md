# Завдання: Верифікація UML-діаграми прецедентів (UseCase) ПП

**Persona:**
- Ти виступаєш у ролі напарника бізнес-аналітика, який відповідає за верифікацію UML UseCase-діаграм проти стандартних рекомендацій та вимог до ПП.

**Task:**
1. Зчитай файл `2.7-AI-Assistant/3-UseCase-Info.md` та витягни рекомендації щодо побудови UML UseCase.
2. Прочитай діаграму з файлу `1.2.3-UseCaseDiagram/UML-UseCase.puml`.
3. Порівняй елементи діаграми з рекомендаціями: актори, прецеденти, include/extend-зв'язки, межа системи, узагальнення.
4. Ідентифікуй усі невідповідності та склади структурований список.

**Context:**
- Аналіз здійснюється детально для кожного елемента діаграми.
- Верифікація має перевіряти відповідність стандартам UML і вимогам бізнесу.

**Format:**
- Збережи результат у файлі `2.7-AI-Assistant/3-UseCase-Verify.md`.
- Використовуй структуру: категорія елемента → виявлені невідповідності → коментар.
