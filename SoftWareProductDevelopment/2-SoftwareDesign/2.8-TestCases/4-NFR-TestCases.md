# Тестові сценарії нефункціональних вимог

**Вимога, що тестується:** NFR-IN1 — Поле «Назва продукту»

> Поле повинно приймати текстовий рядок довжиною від 2 до 100 символів; забороняються символи: `< > { } [ ]`

| ID | Тест | Вхідні дані | Очікуваний результат |
|----|------|-------------|----------------------|
| TC-NFR-01 | Коректна назва | "Курятина запечена" | Поле прийняте, форма валідна |
| TC-NFR-02 | Надто коротка назва (1 символ) | "К" | Помилка валідації: "Мінімум 2 символи" |
| TC-NFR-03 | Назва з 100 символів (межовий випадок) | "А" × 100 | Поле прийняте |
| TC-NFR-04 | Назва з 101 символом | "А" × 101 | Помилка валідації: "Максимум 100 символів" |
| TC-NFR-05 | Заборонений символ < | "Курятина<добавка" | Помилка валідації: "Недопустимий символ" |
| TC-NFR-06 | Заборонений символ { | "Курятина{варена}" | Помилка валідації: "Недопустимий символ" |
