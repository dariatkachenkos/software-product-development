# Тестові сценарії нефункціональних вимог

**Вимога, що тестується:** NFR-IN1 — Поле «Назва сесії / страви»

> Поле повинно приймати текстовий рядок довжиною від 2 до 200 символів; забороняються символи: `< > { } [ ]`

| ID | Тест | Вхідні дані | Очікуваний результат |
|----|------|-------------|----------------------|
| TC-NFR-01 | Коректна назва сесії | "Робота над першою темою сонати" | Поле прийняте, форма валідна |
| TC-NFR-02 | Надто коротка назва (1 символ) | "А" | Помилка валідації: "Мінімум 2 символи" |
| TC-NFR-03 | Назва з 200 символів (межовий випадок) | "А" × 200 | Поле прийняте |
| TC-NFR-04 | Назва з 201 символом | "А" × 201 | Помилка валідації: "Максимум 200 символів" |
| TC-NFR-05 | Заборонений символ < | "Тема<варіація" | Помилка валідації: "Недопустимий символ" |
| TC-NFR-06 | Заборонений символ { | "Акорд{до}" | Помилка валідації: "Недопустимий символ" |
