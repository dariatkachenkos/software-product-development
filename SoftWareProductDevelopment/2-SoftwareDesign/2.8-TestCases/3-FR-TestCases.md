# Тестові сценарії функціональних вимог

**Метод, що тестується:** `CreativeFlowTracker.getAverageQuality(personId: number, from: Date, to: Date): number`

**Опис:** Метод повертає середній рейтинг якості творчих сесій користувача за вказаний період.

## BlackBox-тести (FR1.2)

| ID | Тест | Вхідні дані | Очікуваний результат | Вимога |
|----|------|-------------|----------------------|--------|
| TC-BB-01 | Середній рейтинг при наявності сесій | personId=1, from=2026-05-01, to=2026-05-10; сесії: рейтинги 8, 6, 7 | **(8+6+7)/3 = 7.0** | FR1.2 |
| TC-BB-02 | Середній рейтинг при одній сесії | personId=1, from=2026-05-01, to=2026-05-10; одна сесія з рейтингом 9 | **9.0** | FR1.2 |
| TC-BB-03 | Відсутність сесій за період | personId=1, from=2026-05-01, to=2026-05-10; сесій немає | **0.0** або **null** | FR1.2 |
| TC-BB-04 | Некоректна дата (null) | personId=1, from=null, to=2026-05-10 | **Помилка: InvalidDateError** | FR1.2 |

## WhiteBox-тести (покриття операторів)

```javascript
// Алгоритм getAverageQuality(personId, from, to):
// 1. Перевірити from != null && to != null
// 2. Знайти творчі сесії за (personId, from, to)
// 3. Якщо сесій немає → повернути 0
// 4. Обчислити суму рейтингів / кількість сесій
// 5. Повернути середнє значення
```

| ID | Тест | Мета покриття | Вхідні дані | Очікуваний результат |
|----|------|--------------|-------------|----------------------|
| TC-WB-01 | Покриття оператора перевірки null | Оператор 1 | from = null | InvalidDateError |
| TC-WB-02 | Покриття гілки «сесій немає» | Оператори 2,3 | from=2026-01-01, сесій немає | 0 |
| TC-WB-03 | Покриття обчислення середнього | Оператори 4,5 | from=2026-05-01, 3 сесії з рейтингами 8,6,7 | 7.0 |
